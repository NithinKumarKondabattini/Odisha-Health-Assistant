Odisha Health Assistant 🏥🤖

A professional AI-powered healthcare chatbot web application designed to help residents of Odisha access basic healthcare information and digital health services بسهولة. The platform combines AI symptom analysis, vaccination tracking, appointment booking, and healthcare assistance in one centralized application.

🌟 Project Overview

Odisha Health Assistant is a smart healthcare web application developed to improve access to healthcare-related information and services for people in Odisha.

The application allows users to interact with an intelligent healthcare chatbot, describe symptoms, receive preliminary health guidance, track vaccination schedules, and manage doctor appointments.

The goal of this project is to demonstrate how Artificial Intelligence, web technologies, and automation can be used to create accessible and user-friendly digital healthcare solutions.

⚠️ Disclaimer: The AI-generated symptom analysis and healthcare guidance provided by this application are intended for informational purposes only and should not be considered a replacement for professional medical advice, diagnosis, or treatment.

🚀 Key Features
🤖 AI Healthcare Chatbot

The application includes an intelligent conversational chatbot that allows users to ask healthcare-related questions.

Users can:

Describe general health concerns
Ask questions about common symptoms
Receive preliminary health guidance
Get basic information about healthcare services

Users can provide information about symptoms they are experiencing.

The system analyzes the provided information and generates:

⚙️ Installation and Setup
1. Clone the Repository
git clone <repository-url>
2. Navigate to the Project Directory
cd Odisha-Health-Assistant
3. Install Dependencies
npm install
4. Configure Environment Variables

Create a .env file and configure the required environment variables.

PORT=5000
DATABASE_URL=your_database_url
AI_API_KEY=your_api_key
5. Start the Application
npm run dev

Or:

npm start

The application should now be running locally.
